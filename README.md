# Lingo Journey

My personal language-learning journey with structured vocabulary, grammar workbooks, and speaking practice materials.

## 🌍 Languages

- **English** - Complete CEFR levels (A1-B2) + IELTS vocabulary plan

## 📚 What's Inside

### English Learning Path
- **A1 - Beginner**: 500 words, 15 grammar units, 10 speaking scenarios
- **A2 - Elementary**: 750 words, 15 grammar units, 10 dialogues  
- **B1 - Intermediate**: 1000 words, 20 grammar units, 12 scenarios
- **B2 - Upper Intermediate**: 1500 words, 20 grammar units, 15 scenarios
- **IELTS Vocabulary Plan**: 10-day intensive vocabulary preparation

## 🚀 Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run docs:dev

# Build for production
npm run docs:build

# Preview production build
npm run docs:preview
```
