# A1 - Beginner Level

Welcome to the A1 beginner level! This is your foundation for learning English.

## 📊 Level Overview

**CEFR Level:** A1 (Beginner)  
**Total Vocabulary:** 500 essential words  
**Grammar Units:** 15 fundamental grammar topics  
**Speaking Scenarios:** 10 basic conversation situations

## 🎯 What You'll Learn

At A1 level, you will be able to:

- Introduce yourself and others
- Ask and answer simple questions about personal details
- Interact in a simple way with English speakers
- Understand and use familiar everyday expressions
- Write simple phrases and sentences

## ✅ Learning Path

1. **Week 1-2:** Basic vocabulary (100 words) + Verb "to be"
2. **Week 3-4:** Daily activities vocabulary + Present simple
3. **Week 5-6:** Complete remaining vocabulary + Grammar practice
4. **Week 7-8:** Speaking practice + Review

## 💪 Study Tips

- Learn 10-20 new words every day
- Practice grammar exercises daily
- Speak example sentences out loud
- Review previous lessons regularly
- Don't rush - take your time to master the basics!
